# Dataset notes

`sample_test_cases.csv` is generated by `ml/generate_dataset.py` with a fixed random seed. It contains illustrative synthetic historical test records and rule-derived priority labels. Use it for development/demo only.

For a public dataset, obtain a regression-testing dataset from a research repository or an openly licensed project, verify its license and provenance, then map its fields to the schema in the root README. Do not call this synthetic file a public dataset.
